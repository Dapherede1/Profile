# Dapherede A. Tomisin — Business Performance Analyst Portfolio

A GitHub Pages-ready personal portfolio website.

## Upload to GitHub Pages

1. Create a new GitHub repository named `YOURUSERNAME.github.io`.
2. Upload the contents of this folder (including `index.html`, `style.css`, `script.js`, `assets`, and `projects`).
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Your site will be available at `https://YOURUSERNAME.github.io/`.

## Personalise before publishing

- Replace the DAT initials card in `index.html` with your professional photo if desired.
- Add your CV as `cv.pdf` in the root folder.
- Replace the LinkedIn and GitHub placeholder URLs with your actual profiles.
- Add dashboard/project screenshots to `assets/` and reference them in the project pages.
- Review all project claims and dates before publishing.
